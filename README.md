# 💊 Medication Communication Safety Assistant

A full-stack **university project delivered for a Fiverr client**, designed to improve the clarity and safety of medication instructions using AI-assisted text analysis.

The system converts medication instructions into structured information, identifies potentially ambiguous wording, calculates confidence levels, and flags results that may require further review.

---

## ✨ Key Features

- 💊 **Medication Analysis** — Analyses medication instructions and converts them into structured information
- 🔍 **Information Extraction** — Extracts medication name, strength, dosage, frequency, and route
- 📋 **Medication Information** — Displays common medication use for recognised medicines
- 🧠 **Hybrid AI Analysis** — Combines rule-based processing with NLP
- 📊 **Confidence Scoring** — Identifies ambiguity and highlights results requiring review
- 📷 **OCR Processing** — Extracts text from medication-label images using Tesseract and OpenCV
- 🔐 **Secure Authentication** — User registration and login with JWT authentication
- 👥 **Role-Based Access Control** — Supports USER and ADMIN authorization
- 🗄️ **Persistent Storage** — Stores medication analyses using PostgreSQL
- 🖥️ **Responsive Frontend** — Medical-focused interface built with React and TypeScript
- 🔗 **REST API Integration** — Connects the frontend, Java backend, and Python AI service
